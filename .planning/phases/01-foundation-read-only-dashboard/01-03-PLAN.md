```python
class EventType(StrEnum):
    MESSAGE = "message"
    METADATA = "metadata"
    FILE = "file"
    PARTICIPANT_ADDED = "participant.added"
    PARTICIPANT_REMOVED = "participant.removed"

@dataclass
class Conversation:
    id: str; title: str; channel: str | None
    participants: list[str]; closed: bool; created_at: str

@dataclass
class Event:
    id: str; conversation_id: str; type: EventType
    from_agent: str; data: dict[str, Any]; timestamp: str
```

Jinja2 custom filters available:
- `{{ ts | fmt_time }}` — formats ISO string to "HH:MM:SS" or "never"
- `{{ event.data | fmt_event(event.type) }}` — WRONG. The filter is registered as:
  `_fmt_event(event_type: str, data: dict)` — call as `{{ event.type | fmt_event(event.data) }}`
  Wait — Jinja2 filters receive the piped value as first arg. So:
  `{{ event.type | fmt_event(event.data) }}` means `_fmt_event(event.type, event.data)` — CORRECT.
